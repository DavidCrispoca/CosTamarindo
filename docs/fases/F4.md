## 3. Decisiones que se apartan del documento original

| Tema | Documento original | Implementado | Por qué |
| :--- | :--- | :--- | :--- |
| Lectura del leaderboard | política pública de `SELECT` sobre `scores` | sin acceso directo; solo por la API | una política de tabla no restringe columnas: expondría `user_id` y `session_id` |
| Vista `leaderboard` | vista con top 10 | vista para reportes + función con posición | una vista no conoce al llamante |
| `session_key` | columna en `game_sessions` | no se almacena; se deriva | un volcado de la base no permite firmar puntajes |
| Registro de migraciones | — | `private.schema_migrations` | no contaminar `public` ni la superficie de datos |
