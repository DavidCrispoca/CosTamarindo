plausibilidad y sesión de un solo uso; es el único que escribe en la base y el único que

## 3. Decisiones que se apartan del documento original

| Tema | Documento original | Implementado | Por qué |
| :--- | :--- | :--- | :--- |
| Quién emite el token | Supabase Auth, validado por el backend | el **backend** emite su JWT de 30 min | permite bloqueo real, claim `env` y no expone claves al cliente |
| Login del cliente | cliente → Supabase Auth con `anon key` | cliente → `POST /api/auth/login` | el bloqueo progresivo se aplica en el servidor |
| Credencial de GoTrue | PIN como contraseña | PBKDF de facto: `HMAC(PIN_PEPPER, usuario:PIN)` | GoTrue exige 6 caracteres; el PIN solo tiene 4 |
| Clave HMAC de sesión | columna `session_key` | derivada, nunca almacenada | un volcado de la base no permite firmar |
| Conexión a Postgres | `SUPABASE_DB_URL` genérica | pooler en **modo sesión** (5432) | el modo transacción no soporta sentencias preparadas |
| `position` | columna `position` | `rank_position` | `position` es palabra reservada en Postgres |
