## 5. Cómo se exportó (procedimiento reproducible)

```js
// 1. Abrir sesión sobre el archivo
create_session({ fileKey: "qI8jr7abLu6tIpL0MnL8Ol", task: "..." })

// 2. Pedir el asset por nodo
download_assets({ fileKey, nodeId: "1:440", defaultFormat: "png", defaultScale: 3 })

// 3. La respuesta es JSON + un pie "curl ..." (no parseable directo).
//    Extraer la URL con regex y descargarla de inmediato: caduca en minutos.
```

Notas operativas:

- `download_assets` devuelve **string**, no objeto → `JSON.parse` falla; usar regex
  sobre `"export": {... "url": "..."}` y `"svgAssets": [{"url": "..."}]`.
- Con `scale: 3` un ítem pesa ~10–13 KB.
- Máximo real con el plan Starter: **3 exportaciones** antes del corte.
